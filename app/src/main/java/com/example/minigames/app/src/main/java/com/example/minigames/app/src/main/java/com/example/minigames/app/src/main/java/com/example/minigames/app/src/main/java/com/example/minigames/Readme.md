# 🎮 Minigames

Kotlin + Jetpack Compose ile yazılmış, içinde 3 minigame bulunan Android uygulaması.

## Oyunlar
- ❌⭕ XOX (2 kişilik)
- 🃏 Hafıza Kartları (hamle sayacı)
- 🔢 Sayı Tahmin (1-100)

## Kurulum
1. Android Studio'da **New Project → Empty Activity** (Compose) aç.
2. Package name: `com.example.minigames`
3. `app/src/main/java/com/example/minigames/` içindeki dosyaları bu repodakilerle değiştir/ekle.
4. Çalıştır ▶️
